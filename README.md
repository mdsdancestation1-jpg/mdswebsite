# M.D.S DANCE STATION Website

Professional, high-performance website for **M.D.S DANCE STATION**, founded by Minku Kumar in Patna, Bihar.

## Features
- **Hero & Course Showcase**: Explore dance courses including Hip Hop, Bollywood, Kathak, Zumba, and Western styles.
- **YouTube Shorts Showcase**: Embedded YouTube Shorts player for studio choreography.
- **Social Media Hub (White Theme Big Cards)**: Direct links to official YouTube (`@MDSDANCESTATION`), Instagram (`@mds_dance_station`), and Facebook channels.
- **Responsive Navigation & Mobile Drawer**: Smooth glassmorphic navigation bar and mobile drawer.
- **Student Performance Gallery**: Highlighting student achievements and studio life.

## Running Locally
To launch a local dev server:
```bash
python -m http.server 8080
```
Open `http://localhost:8080` in your web browser.
